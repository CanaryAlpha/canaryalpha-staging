# Neue Montreal (licensed)

Neue Montreal (Pangram Pangram) needs a commercial license, so the font
files are not in this repo. To try it in the font test panel (`?fonts=1`),
add the licensed web fonts here with these names:

- `NeueMontreal-Regular.woff2` (400)
- `NeueMontreal-Medium.woff2` (500)
- `NeueMontreal-Bold.woff2` (700)

The panel enables Neue Montreal once `NeueMontreal-Regular.woff2` is here.
